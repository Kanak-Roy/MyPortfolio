# Personal Portfolio Website

A clean, responsive personal portfolio website showcasing my background as a Computer Science & Engineering graduate and Software Quality Assurance (SQA) enthusiast. The site highlights my core testing competencies, featured projects, services, and contact details.

---

## 🚀 Overview

This website serves as an interactive resume and central hub for my professional work:
- **Hero & About:** Brief introduction, educational background, and downloadable CV.
- **Core Services:** Highlights of testing areas including Manual Testing, Automation Testing, and API Testing.
- **Featured Projects:** Showcases QA projects such as the EchoGPT Software Testing Project (covering functional testing, Postman API testing, and bug reporting).
- **Contact:** Integrated message form and direct links to GitHub, LinkedIn, Facebook, and Instagram.

---

## 🛠️ Tech Stack & Libraries

- **HTML5 & CSS3:** Semantic markup and responsive layout styling.
- **JavaScript:** Custom interactive scripts (`script.js`).
- **[Typed.js](https://github.com/mattboldt/typed.js/):** Dynamic animated typing effect.
- **[Boxicons](https://boxicons.com/):** Vector icons for navigation, services, social media, and ratings.
